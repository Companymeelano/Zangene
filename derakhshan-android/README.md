# نسخه اندرویدی درخشان

این پوشه پوسته مستقل اندروید را برای محتوای محلی `../derakhshan-wholesale` فراهم می‌کند؛ نسخه وب و منابع تصویری در زمان ساخت داخل APK قرار می‌گیرند و برنامه برای کار کردن به اینترنت نیاز ندارد. نسخه ۲٫۱ با حفظ آیکن سه‌بعدی اختصاصی، صفحه آغاز، جزئیات محصولات و منتخب‌های محلی، چیدمان موبایل، نوار دسترسی، دسته‌ها و حالت خالی منتخب‌ها را بهبود می‌دهد. حداقل نسخه سیستم‌عامل Android 6 (API 23) است و برای نمایش صحیح رابط، به Android System WebView به‌روز نیاز دارد.

برای بازسازی با Android Studio یا Gradle به JDK 17، Gradle 8.7 و Android SDK 35 نیاز است. از این پوشه اجرا کنید:

```sh
gradle :app:assembleDebug
```

فایل حاصل در `app/build/outputs/apk/debug/` قرار می‌گیرد. برای نسخه انتشار، از کلید امضای اختصاصیِ مالک برنامه استفاده کنید و آن را خارج از مخزن به‌صورت امن نگه دارید؛ APKهای امضاشده با کلیدهای متفاوت روی هم به‌روزرسانی نمی‌شوند.

همه فایل‌ها از مسیر مجازی HTTPS فقط از دارایی‌های داخل برنامه خوانده می‌شوند؛ دسترسی به اینترنت و فایل‌های دستگاه غیرفعال است. شناسه منتخب‌ها و شناسه و مقدار محصولات استعلام در فضای محلی WebView نگهداری می‌شوند. دکمه کپی از کلیپ‌بورد اندروید و دانلود از پنجره انتخاب محل ذخیره سیستم استفاده می‌کند. نام و شماره تماس به سرور فرستاده یا در فهرست محلی ذخیره نمی‌شوند. محصولات و تصاویرشان نمونه‌اند و متن استعلام باید توسط کاربر از راه ارتباطی معتبر برای فروشنده فرستاده شود. حساب کاربری، پنل مدیریت و ارسال واقعی استعلام هنوز پیاده‌سازی نشده‌اند و به زیرساخت و اطلاعات واقعی کسب‌وکار نیاز دارند.
