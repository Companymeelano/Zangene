# مجموعه آیکن سه‌بعدی — نسخه تست

این APK از نسخه آزمایشی آفلاین قبلی `ASIYE_STORE_PEARL_ICON_TEST.apk` ساخته شده، نه از سورس کامل اندروید که در فضای کاری فعلی موجود نیست. `tools/add_test_jewel_icons.py` پس از decode با apktool، ده فایل PNG شفاف ۲۵۶ پیکسلی را به assets اضافه و فقط loader آیکن را اصلاح می‌کند. رندر برنامه آن‌ها را مانند آیکن‌های قبلی در محدودهٔ همان View متناسب‌سازی می‌کند. فهرست نگاشت‌ها شامل تماس، واتساپ، اینستاگرام، تاج مدیریت، هدیه، قلب منتخب، نمودار، هوش مصنوعی، دوربین و جعبه است. قلب غیرمنتخب به وکتور اولیه بازمی‌گردد. آیکن‌های دیگری که تصویر اختصاصی ندارند همچنان وکتور باقی می‌مانند.

این بسته با package جداگانه `com.asiyestore.admin.jewelcollectiontest` و امضای موقت ساخته شده؛ به‌روزرسان نسخه‌های قبلی نیست. فاقد مجوز اینترنت و شامل بای‌پس ورود مدیریت برای تست است؛ نسخه تولید یا تحویل اطلاعات واقعی نیست. نیاز به بررسی نصب، خوانایی و تطبیق ابعاد و تمام وضعیت‌ها روی دستگاه واقعی دارد.

پیش از انتشار تولیدی، سورس اصلی و مسیر ساخت امن باید بازیابی شوند، آیکن‌ها به سورس افزوده شوند و ادغام و تست و امضای رسمی انجام شود. فایل کلید موقت نگهداری نشده است.
