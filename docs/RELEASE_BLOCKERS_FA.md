# وضعیت آماده‌سازی نسخه قابل انتشار اسیه

نتیجه: **آماده انتشار نیست**. APK اخیر فقط آزمایشی آفلاین است و ورود مدیر بدون رمز دارد. به نسخه نهایی تغییر نام داده یا با داده واقعی استفاده نشود.

## بررسی‌های این مرحله

- سورس اندروید در working tree فعلی وجود ندارد. در Git سورس قدیمی‌تری وجود دارد، اما تم پیش‌فرض پاستلی، منوی ساده و نشان جدید را ندارد؛ بازگرداندن آن به‌عنوان سورس آخرین نسخه، تغییرات را به عقب برمی‌گرداند. APKهای آزمایشیِ اخیر حاوی تغییرات کامپایل‌شده و بخشی از آن‌ها وصلهٔ باینری هستند، نه سورس بازتولیدپذیر.
- بخش backend فعلی در working tree موجود نیست. در سورس ردیابی‌شده، ورودی `artisan` و bootstrap لاراول و پیاده‌سازی فعلی AI router موجود نیست. یکپارچگی، احراز هویت، migration، خدمات AI و پرداخت واقعی تأیید نشده است.
- مادهٔ امضای تاریخی در Git ردیابی شده و سابقاً افشا شده است. استفاده مجدد از آن امن نیست؛ گردانندهٔ سامانه باید مستقل از این گفتگو آن را بررسی و چرخش دهد و برای تاریخچهٔ Git و نسخه‌های منتشرشده تصمیم مناسب بگیرد. حذف یک فایل از نسخهٔ جدید تاریخچه را پاک نمی‌کند.
- امضای نسخه‌های تست موقت بوده و نمی‌توان آن‌ها را با همان هویت به‌روزرسانی کرد. نصب نسخه جدید با package مجزا داده‌های نسخه دیگر را منتقل نمی‌کند.
- آزمون دستگاه واقعی، accessibility، ارتقای پایگاه داده و اتصالات واقعی برای انتشار انجام نشده‌اند.

## مسیر پیشنهادی

1. بازیابی آخرین سورس کامل اندروید شامل تم، اصلاحات امنیتی، migration و طراحی فعلی؛ نه صرفاً APK و نه پروژه قدیمی. فایل‌ها باید بدون رمزها و کلیدهای واقعی به فضای پروژه افزوده شوند.
2. تکمیل و اتصال پروژه Laravel واقعی، قرارداد احراز هویت، سرویس‌های تصویر/ویدیو و مرجع قیمت قابل بررسی؛ آدرس‌ها و مدل‌ها در تنظیمات محیط سرور باشند. عملیات هزینه‌دار با نتیجه نامعلوم نباید خودکار تکرار شود.
3. بازسازی قابل تکرار، اسکن محرمانگی و بررسی مدیریت امن کلید امضا خارج از مخزن و گفتگو. بازیابی منبع و امضای جدید الزاماً امکان به‌روزرسانی نصب قبلی را تضمین نمی‌کند؛ پیش از هر تغییر یا حذف نصب، راهکار انتقال داده باید جداگانه آزمایش شود.
4. آزمون migration روی کپی داده، تست واحد و integration، تست نقش‌ها، پرداخت، RTL، ابعاد/کنتراست و عملکرد روی چند دستگاه. انتشار فقط پس از رفع خطاها.

`python3 tools/release_readiness.py` چند پیش‌شرط ثابت را بدون خواندن یا نمایش مقدار هیچ رمز بررسی می‌کند. حتی قبولی آن به معنی تأیید امنیت، پرداخت، سرویس‌ها یا کیفیت بصری نیست.
