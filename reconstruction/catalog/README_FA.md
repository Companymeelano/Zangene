# پیش‌نویس کاتالوگ بیز برای اسیه استور

این مجموعه فقط شامل سه محصول شناسایی‌شده در نتایج جست‌وجو است و فهرست کامل سایت نیست. فایل `bizmlm_drafts.json` شامل نام، اندازه، شرح، کپشن، کلیدواژه، لینک منبع و قیمت مرجع است. قیمت سایت در نتایج به ریال دیده شده و قیمت مرجع تومان با تقسیم بر ۱۰ محاسبه شده است. **زمان به‌روزرسانی نتایج و قیمت واقعی روز مشخص نیست.** قیمت فروش تأییدشده و موجودی عمداً خالی‌اند و همهٔ محصولات منتشرنشده هستند.

تصویر پس‌زمینهٔ مستقل صورتی در `../android/assets/catalog/biz_pink_backdrop.png` با هوش مصنوعی ساخته شده و تصویر هیچ محصولی نیست. لینک تصاویر مرجع در فایل JSON از یک سایت ثالث است، نه سایت رسمی بیز؛ برای استفاده باید هویت بسته‌بندی و مجوز تصویر بررسی شود. هیچ تصویر محصول شخص ثالثی در برنامه درج یا منتشر نشده است.

**این فایل‌ها هنوز به برنامه نصب‌شده، پایگاه داده یا APK متصل نیستند.** واردسازی خودکار عمداً خاموش است تا اطلاعات و قیمت ساختگی یا قدیمی به کاربران نمایش داده نشود. قبل از واردسازی، باید فهرست کامل و مشخصات هر کالا، قیمت و موجودی به‌روز، واحد پول، حق استفاده از عکس‌ها و سازگاری با داده‌های موجود تأیید و مسیر واردسازی با تراکنش آزمایش شود.
