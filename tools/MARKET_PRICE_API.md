# قرارداد اتصال قیمت بازار (۷.۱.۸)

سرویس قیمت به طور پیش‌فرض تنظیم نشده و هیچ اتصال مستقیمی به ترب، دیجی‌کالا یا باسلام ادعا نمی‌شود. مالک فروشگاه باید سرویس HTTPS قابل اعتماد و مجاز با این قرارداد تأمین کند؛ در صورت نیاز به API key، آن را در بک‌اند امن خود نگه دارید، نه در نشانی یا APK. برنامه رابط تنظیم کلید این سرویس را ندارد. اپ صرفاً با تأیید کاربر درخواست می‌فرستد.

`POST /your-price-endpoint`، با `Content-Type: application/json`، UTF-8:

```json
{"name":"چای سیاه", "brand":"ساقدوش", "volume":"۵۰۰ گرم"}
```

HTTP 200 و JSON، حداکثر ۳۰ پیشنهاد و ۲۵۶ کیلوبایت:

```json
{"offers":[
 {"source":"فروشگاه الف", "title":"چای سیاه ۵۰۰ گرم", "url":"https://shop.example/item/1", "price_toman":200000, "observed_at_ms":1700000000000},
 {"source":"فروشگاه ب", "title":"چای سیاه ۵۰۰ گرم", "url":"https://other.example/item/2", "price_toman":220000, "observed_at_ms":1700000000000}
]}
```

زمان مثال عمداً قدیمی است؛ سرویس باید زمان مشاهده واقعی UTC را به میلی‌ثانیه یونیکس بفرستد. مبلغ عدد صحیح به **تومان** است، نه ریال. فقط HTTPS، URL یکتا، قیمت مثبت و مشاهده طی ۲۴ ساعت گذشته (با حداکثر ۵ دقیقه خطای ساعت آینده) پذیرفته می‌شود. کاربر با مشاهده عنوان، منبع، نشانی و زمان باید حداقل دو پیشنهاد دقیقاً مشابه را انتخاب کند؛ میانگین حسابی انتخاب‌ها پیشنهاد قابل ویرایش است، نه قیمت تأییدشده بازار. صحت نام منبع، واحد، اصالت کالا، موجودی و اطلاعات خود سرویس توسط اپ مستقلاً قابل اثبات نیست. سرویس باید مجوز دسترسی به منابع را داشته باشد. تغییر نام، برند، حجم یا قیمت حین درخواست مانع اعمال پاسخ می‌شود. این قرارداد دسترسی بدون احراز هویت در سطح اپ دارد؛ فراهم‌کننده باید حفاظت و کنترل سوءاستفاده سمت بک‌اند را طراحی کند. داده‌های محصول به سرویس انتخاب‌شده ارسال می‌شود.
