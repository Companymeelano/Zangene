# درخشان | Nute Store

فروشگاه فارسی آجیل و خشکبار در پوشه [`derakhshan-wholesale`](derakhshan-wholesale/) و پوسته اندروید در [`derakhshan-android`](derakhshan-android/) قرار دارند. فایل فشرده اولیه دست‌نخورده باقی مانده است.

**این نسخه آزمایشی است:** محصولات و تصاویر نمونه‌اند، قیمت و موجودی واقعی هنوز ثبت نشده‌اند، و پرداخت فقط شبیه‌سازی محلی است. هیچ پولی کسر و هیچ سفارشی ثبت یا ارسال نمی‌شود. راه‌اندازی فروش واقعی به اطلاعات تأییدشده محصولات، سامانه سفارش و اتصال امن به درگاه پرداخت نیاز دارد.

برای مشاهده نسخه وب با Python 3:

```sh
npm run dev
```

سپس `http://localhost:4173` را باز کنید. توضیحات بیشتر درباره داده‌ها و محدودیت‌ها در [راهنمای فروشگاه](derakhshan-wholesale/README.md) و روش ساخت APK در [راهنمای اندروید](derakhshan-android/README.md) آمده است.

## آزمون رابط

با Node.js و Chromium:

```sh
npm ci
npx playwright-core install chromium
npm run dev                 # در ترمینالی جداگانه
npm run test:ui
npm run test:android-web
npm run test:contact-links  # به JDK نیاز دارد
```

آزمون‌ها مسیر خرید آزمایشی، سبد و مهاجرت داده‌های نسخه قبلی، ابعاد مختلف، بزرگ‌نمایی متن، وضعیت ناوبری، لمس، کیبورد، دسترس‌پذیری، اطلاعات تماس، فهرست مجاز پیوندها و اجرای دارایی‌ها در مبدأ مجازی اندروید را بررسی می‌کنند. `BASE_URL`، `CHROMIUM_PATH` و `CHROMIUM_ARGS` اختیاری‌اند. برای آزمودن دارایی‌های استخراج‌شده از APK می‌توان `APK_ASSETS_DIR` را به مسیر پوشه `assets` آن تنظیم کرد. این آزمون‌ها جای نصب و بررسی APK روی دستگاه واقعی را نمی‌گیرند.
