# ASIYE STORE — LUXURY BEAUTY COMMERCE ECOSYSTEM

## 1. PROJECT OVERVIEW
**Brand Name:** ASIYE STORE  
**Slogan:** Your Beauty, Your Signature.  
**Mission:** Build a real, operational, secure, ultra-premium luxury beauty commerce ecosystem (Customer Website, Admin Dashboard Web, Android Admin App, Central Backend & API).  
**Primary Language:** Persian (Farsi)  
**Direction:** RTL (Right-to-Left)  
**Tech Stack:**
- Backend: Laravel (PHP)
- Database: MySQL / MariaDB
- Frontend: HTML5, CSS3, JavaScript (Modular CSS)
- API: RESTful
- Android: Kotlin + Jetpack Compose (MVVM + Clean Architecture)
- Notifications: Firebase Cloud Messaging
- Storage: Local / Object Storage
